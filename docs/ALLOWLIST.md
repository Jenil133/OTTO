# OTTO — Target Allowlist (Zone-1 read-only targets, architecture D5)

Every `target` in a Plan (CONTRACTS.md §2) must appear here — open web only,
read-only actions only. The planner is hard-gated to this list
(`schemas.PlanSubtask.on_allowlist`); an off-list target becomes a clarifying
question, never a browser drive.

**Confirmed** = the three demo primaries. **Candidate** = Zone-1 sites the mock
planner can already target; Phase 2 Task B empirically scores each on Saturday
(login-free? bot-defense? layout-stable? fast?) and cuts the losers. Viewport
notes + winning phrasing get filled during that agent tuning.
